# Мой пет-проект

## Идея
Телеграм-бот для учёта личных расходов. Пользователь пишет боту
сумму и категорию траты (например, «500 еда»), а бот сохраняет
запись и по команде `/stats` показывает, сколько потрачено
за неделю или месяц по каждой категории.

## Стек
- **Язык:** Python 3.12
- **Библиотеки:** aiogram 3 (телеграм-бот), SQLite (хранение данных)
- **Дополнительно:** Docker для упаковки, GitHub Actions для CI

## Цель
Научиться:
1. Писать асинхронный код на Python (`async`/`await`)
2. Работать с Telegram Bot API
3. Хранить данные в базе и делать простую аналитику
4. Упаковывать приложение в Docker и автоматизировать сборку через CI
